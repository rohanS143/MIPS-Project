# Twenty-One Number Trick (MIPS Assembly)

## Project Overview

This project implements the classic **21 Number Magic Trick** in **MIPS Assembly Language**.

The program asks the user to think of a number between 1 and 21. It then displays the numbers in three columns and asks the user which column contains their chosen number. After repeating this process three times, the program correctly identifies the user's number.

The project demonstrates low-level programming concepts including loops, arrays, memory management, user input validation, function calls, and algorithm implementation in MIPS Assembly.

---

## Program Flow

1. User thinks of a number between 1 and 21.
2. Numbers are displayed in three columns.
3. User selects the column containing their number.
4. Columns are rearranged according to the selection.
5. Steps 2–4 are repeated three times.
6. The program reveals the chosen number.
